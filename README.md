# StuGro website

Marketing and content site for StuGro, a student-run finance organization in New Jersey.
Next.js 16 (App Router), TypeScript, Tailwind CSS v4, Framer Motion, Recharts, Lucide.

```bash
npm install
npm run dev
```

- **Filling in content:** see [SETUP.md](./SETUP.md). All content lives in `/content`.
- **Changing the look:** edit `styles/tokens.css` (colors, type, spacing, radius, shadow, motion).
